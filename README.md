# 🌏 트라이링고 (Trilingo)

가족이 함께 쓰는 **영어 · 중국어 · 일본어** 학습 사이트. 빌드 도구 없이 HTML/CSS/JS만으로 동작하며 GitHub Pages에 올려 휴대폰·PC 어디서나 접속합니다.

## 기능
- **학습**: 상황별 단어 / 상황별 문장 / 레벨별 단어 / 레벨별 문장 (같은 단어 풀을 두 가지 축으로 분류)
  - 한 카드에 한국어 뜻 + 선택한 언어(영/중/일)가 함께 표시 → 세 언어 동시 학습
  - 발음 표기: 중국어 **한어병음**, 일본어 **히라가나·가타카나·로마자**, 영어 **IPA** — 화면 상단 칩으로 켜고 끄기
  - 🔊 버튼: 브라우저 내장 TTS로 원어 발음 듣기
  - "학습 완료" 버튼으로 기록 → 테스트 출제 범위가 됨
- **테스트**: 상황별/레벨별 × 단어/문장, 4지선다 또는 직접 입력, 출제 대상(학습 완료한 것만 / 취약 항목 / 전체), 언어·문제 수 선택
- **복습**: 틀린 횟수 ≥ 맞은 횟수인 "취약 항목" 자동 모음 + 취약 항목 테스트
- **노래로 배우기**: 유튜브 원곡 임베드 + 핵심 구절 발췌·발음·뜻 + 문법/단어/관용어구 해설, 구절별 학습 체크, 내 가사 메모(본인 기록에만 저장)
- **레벨 시스템**: 학습 완료·테스트 정답·노래 구절 학습으로 XP 획득, Lv.1 새싹 → 폴리글랏
- **가족별 기록**: 학습자 프로필(이름·아바타·언어 선택)마다 학습 기록·테스트 이력·XP 분리 저장

## 폴더 구조
```
index.html          진입점
css/style.css       스타일(모바일 우선, 다크모드 자동)
js/app.js           화면·라우팅·테스트 로직
js/storage.js       저장소(localStorage 기본, Firebase 선택)
js/kana.js          히라가나↔가타카나, 로마자 변환
js/config.js        저장소 설정(Firebase 붙이는 곳)
data/words.js       단어 132개 (10개 상황 × 레벨 1~3)
data/sentences.js   문장 60개
data/songs.js       노래 9곡 (언어별 3곡)
backup/             수정 전 버전 보관
WORKLOG.md          작업 일지
```

## 콘텐츠 추가하기
- 단어: `data/words.js`에 `W("고유id", "상황키", 레벨, "한국어", "영어", "IPA", "중국어", "병음", "일본어", "히라가나 읽기")` 한 줄 추가. **기존 id는 바꾸지 마세요**(학습 기록이 id 기준).
- 문장: `data/sentences.js`에 같은 방식(`S(...)`).
- 노래: `data/songs.js`의 객체를 복사해 `id`, `lang`, `title`, `artist`, `yt`(유튜브 영상 ID), `lines` 채우기. 저작권 때문에 전체 가사 대신 핵심 구절만 발췌하는 구조입니다.
- 상황 카테고리 추가: `data/words.js` 상단 `TL_SITUATIONS`에 항목 추가 후 그 키로 단어/문장을 넣으면 됩니다.

## 저장 방식
**Firebase Firestore 동기화가 켜져 있습니다** (프로젝트 `trilingo-2eaf8`, 가족 코드는 `js/config.js`).
- 어느 기기에서든 같은 이름으로 "새 학습자"를 만들면 기존 기록에 자동 연결됩니다. 홈 화면에는 가족 전체 프로필이 보이므로 자기 이름을 누르기만 하면 됩니다.
- 쓰기는 2.5초 디바운스, 사용자당 문서 1개 → 무료 한도(일 쓰기 2만/읽기 5만)의 1% 수준.
- 보안 규칙은 `firestore.rules` (`firebase deploy --only firestore:rules`로 배포). 로그인 없이 가족 코드로만 구분하므로 코드를 외부에 올리지 마세요(이 저장소가 공개라면 코드가 노출됩니다 → 가족 학습 기록 외 민감 정보는 저장되지 않음).
- 백업: 설정 > 백업 파일 내보내기 / 가져오기(JSON)

### 다른 Firebase 프로젝트로 옮기려면
1. https://console.firebase.google.com 에서 프로젝트 추가 → Firestore Database 생성
2. `firebase login` 후 `.firebaserc`의 프로젝트 ID 변경 → `firebase deploy --only firestore:rules`
3. 프로젝트 설정 > 내 앱 > 웹 앱의 `firebaseConfig`를 `js/config.js`에 붙여 넣기

## 로컬에서 열기
`index.html`을 더블클릭하면 그대로 열립니다(서버 불필요). 유튜브 임베드는 `file://`에서 막힐 수 있으니 배포 주소에서 확인하세요.
